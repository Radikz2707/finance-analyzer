# Правило: Одинарные кавычки для всех строк

## Обязательное требование

Все строковые литералы в коде должны быть обернуты **исключительно в одинарные кавычки** (`'`), а не в двойные (`"`).

## Примеры

### ✅ Правильно
```typescript
const greeting = 'Hello, world!';
const message = 'Ошибка: файл не найден';
ctx += '    ⚠️ DATA_STATUS = STALE\n';
```

### ❌ Неправильно
```typescript
const greeting = "Hello, world!";
const message = "Ошибка: файл не найден";
ctx += "    ⚠️ DATA_STATUS = STALE\n";
```

## Исключения

- Шаблонные строки (backticks `` ` ``) разрешены для интерполяции переменных
- Внутри шаблонных строк строковые литералы также должны использовать одинарные кавычки, если они не содержат интерполяции

## Автоматическая проверка

Правило настроено в `eslint.config.js`:
```javascript
quotes: ['error', 'single', { avoidEscape: true }]
```

Для автоматического исправления:
```bash
node node_modules/eslint/bin/eslint.js --fix "путь/к/файлу"
```

## Применение

Это правило применяется ко **всем** файлам проекта:
- `src/js/**/*.ts`
- `src/js/**/*.js`
- Конфигурационные файлы в корне проекта

При генерации или изменении кода всегда используй одинарные кавычки для строковых литералов.
