### P0.1 Подсчёт токенов: `total_tokens` → `eval_count`

- **Файл**: [`ollama-stream.ts`](../src/js/modules/ai-advisor/ollama-stream.ts:202)
- **Проблема**: Ollama в финальном чанке возвращает `eval_count` (число сгенерированных токенов), а не `total_tokens`. Поэтому в логе всегда «0 токенов».
- **Фикс**: читать `json.eval_count ?? json.total_tokens ?? 0` в 3 местах (стрим-режим строка 202, хвост буфера строка 221, не-стрим строка 264).

### P0.2 «JSON-блок не найден в ответе»

- **Файлы**: [`prompt-templates.ts`](../src/js/modules/ai-advisor/prompt-templates.ts:125), [`ollama-stream.ts`](../src/js/modules/ai-advisor/ollama-stream.ts:94), [`ai-client.ts`](../src/js/modules/ai-advisor/ai-client.ts:1224)
- **Проблема**: промпт требует 7 текстовых секций + JSON-блок **в КОНЦЕ**. Модель сгенерировала 8028 символов (~4000+ токенов русского текста) и упёрлась в `num_predict: 4096` до того, как дошла до JSON. `extractJsonFromAiResponse` вернул `null` → `structuredJson = null` → все 12 активов получили детерминированный fallback вместо AI-рекомендаций.
- **Варианты фикса (выбрать 1–2)**:
  1. **Перенести JSON-блок в НАЧАЛО ответа** — «Сначала JSON, потом текст». Модель гарантированно успевает выдать JSON до лимита токенов. Минимальное изменение промпта.
  2. **`format: 'json'`** в запросе к Ollama — принудительный JSON-режим (но тогда теряется narrative-текст; подходит только если JSON — единственный нужный вывод).
  3. **Увеличить `num_predict` до 8192** — но это ещё медленнее (582с → ~1000с), не рекомендуется без P0.4.
- **Рекомендация**: вариант 1 (JSON первым) + P0.1 для диагностики.

### P0.3 Таймаут на чтение стрима

- **Файл**: [`ollama-stream.ts`](../src/js/modules/ai-advisor/ollama-stream.ts:148)
- **Проблема**: `timeout: 300000` (5 мин) применяется только к `axios.post` (установке соединения). Чтение потока (`response.data.on('data')`) таймаута не имеет — ответ шёл 581 983 мс.
- **Фикс**: добавить `setTimeout` на общую длительность стрима (например, 10 мин) с `response.data.destroy()` и resolve с `success: false, error: 'Stream timeout'`.

### P0.4 Скорость модели

- **Файлы**: [`ai-config.ts`](../src/js/modules/ai-advisor/ai-config.ts:38), [`ollama-stream.ts`](../src/js/modules/ai-advisor/ollama-stream.ts:94)
- **Проблема**: `qwen3.5:9b` генерирует ~14 символов/с (8028 символов за 581с) — модель работает на слабом железе (вероятно CPU).
- **Варианты**:
  1. Переключить дефолт на меньшую модель (`qwen3:4b` / `qwen2.5:3b`) — в 2–3 раза быстрее.
  2. При наличии `GIGACHAT_API_KEY` поднять приоритет GigaChat (облако, ~секунды).
  3. Сократить промпт: убрать требование «развёрнуто, с аргументацией» → короче ответ → быстрее.
  4. Кэш уже работает (7836 символов сохранено) — повторные прогоны быстрые.
